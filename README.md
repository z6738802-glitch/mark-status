# mark-status

עמוד סטטוס ללקוחות של MARK Automations. כל לקוח מקבל קישור סודי שמראה איפה עומדת העבודה עליו, והצוות מעדכן הכל ממסך ניהול אחד.

## מבנה

```
server.js              שרת Express: API ציבורי, API ניהול, התחברות
public/status.html     העמוד שהלקוח רואה
public/icons.js        אייקוני Lucide משותפים
admin/index.html       מסך הניהול
db/schema.sql          סכימת בסיס הנתונים (mark_status)
Dockerfile             תמונה ל-CapRover
captain-definition     הגדרת CapRover
```

## התקנה על CapRover

1. **יצירת אפליקציה** בשם `mark-status`. אין צורך ב-Persistent Data.
2. **משתני סביבה** בלשונית App Configs:

| משתנה | ערך |
|---|---|
| `DATABASE_URL` | `postgresql://USER:PASS@srv-captain--sdb-db:5432/postgres` |
| `EDITORS` | `צביקי:סיסמה;אריה:סיסמה;שרוליק:סיסמה` |
| `SESSION_SECRET` | ערך קבוע מ-`openssl rand -hex 32` |
| `NODE_ENV` | `production` |

3. **HTTPS**: בלשונית HTTP Settings להפעיל HTTPS ולסמן Force HTTPS. בלי זה עוגיית ההתחברות לא נשמרת ואי אפשר להיכנס לניהול.
4. **פריסה**: בלשונית Deployment לחבר את הריפו הזה (branch `main`), או `caprover deploy` מהטרמינל.

הסכימה נוצרת אוטומטית בעלייה הראשונה. היא יושבת בסכימה נפרדת `mark_status` ולא נוגעת בטבלאות קיימות. לכיבוי: `AUTO_MIGRATE=false`.

## שימוש

- **ניהול**: `https://<כתובת>/admin`, כניסה עם שם עורך וסיסמה.
- **לקוח חדש**: נוצר קישור אקראי. כפתור "העתק קישור" מעתיק אותו.
- **נושא**: כותרת, תיאור, סטטוס, אייקון, אחראי, יעד, מה עוצר, ורשימת שלבים שאפשר לסמן.
- **סדר**: חיצים ליד כל נושא.
- **קישור שדלף**: "צור קישור חדש" מבטל את הקודם. "השבת קישור" עוצר גישה בלי למחוק.
- **היסטוריה**: כל הוספה, מחיקה ושינוי סטטוס נרשמים עם תאריך ומוצגים ללקוח.

ההתקדמות הכוללת בראש העמוד מחושבת לפי השלבים המסומנים בכל נושא. נושא שהושלם נספר כמאה אחוז.

## אבטחה

- בסיס הנתונים לא חשוף לאינטרנט, רק האפליקציה ניגשת אליו ברשת הפנימית.
- קישור לקוח הוא מזהה אקראי של 16 תווים, והלקוח רואה רק את הנתונים שלו.
- הגבלה של 10 ניסיונות התחברות לרבע שעה לכל כתובת.
- אין סודות בקוד, הכל במשתני סביבה.

## פיתוח מקומי

```bash
npm install
DATABASE_URL=postgresql://localhost/postgres EDITORS="dev:dev" npm run dev
```
